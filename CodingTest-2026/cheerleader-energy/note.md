# Problem: Cheerleader Energy
 
문제 요약: 같은 팀을 응원하는 치어리더들의 연속 구간 길이를 제곱하여 팀별 응원 에너지의 합을 구하는 문제

## 풀이

### 문제 정보
- 난이도: Lv 01 
- 주제: 문자열, 구현, 연속 구간, 런 길이 인코딩
- 최초 풀이: 260729 
- 수정 버전: 260805 

### 접근법
1. Solution1: 연속 구간 길이 계산 
   - 문자열을 한 번 순회하면서 현재 팀의 연속 길이를 계산하고, 팀이 변경될 때 구간 길이의 제곱을 해당 팀 에너지에 누적한다.

## Solution1: 연속 구간 길이 계산
### 코드 설계
1. 첫 번째 치어리더가 응원하는 팀을 현재 팀으로 설정한다.
2. 팀별 에너지와 현재 연속 구간 정보를 초기화한다.
   - `redEnergy`: 빨간 팀의 누적 응원 에너지
   - `blueEnergy`: 파란 팀의 누적 응원 에너지
   - `currentTeam`: 현재 연속 구간의 팀
   - `count`: 현재 연속 구간의 길이
3. 두 번째 문자부터 문자열을 순회한다.
   - 현재 문자가 `currentTeam`과 같으면 `count`를 증가시킨다.
   - 현재 문자가 `currentTeam`과 다르면 기존 구간의 에너지를 계산한다.
     - 구간 에너지 `count × count`를 해당 팀에 누적한다.
     - `currentTeam`을 현재 문자로 변경한다.
     - `count`를 `1`로 초기화한다.
4. 반복문 종료 후 마지막 연속 구간의 에너지를 해당 팀에 누적한다.
5. 빨간 팀과 파란 팀의 에너지를 공백으로 구분하여 출력한다.

### 코드 구현
- 핵심 포인트
  - 같은 문자가 연속되는 동안에는 구간 길이만 증가시킨다.
  - 문자가 변경되는 시점에 하나의 연속 구간이 완성된다.
  - 마지막 구간은 반복문 안에서 처리되지 않으므로 반복문 종료 후 별도로 계산한다.
  - 문자열을 한 번만 순회하고 별도의 배열을 사용하지 않는다.
- 시간복잡도: O(N)
- 공간복잡도: O(1)
