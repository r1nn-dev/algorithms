# Problem: Bank Account Transactions
 
문제 요약: 고객별 입출금 거래를 순서대로 처리하여 모든 거래 이후의 계좌 잔액을 구하는 문제

## 풀이

### 문제 정보
- 난이도: Lv 01 
- 주제: 구현, 시뮬레이션, 배열
- 최초 풀이: 260729 
- 수정 버전: 260806

### 접근법

   - 거래를 입력 순서대로 한 번씩 확인하면서 고객별 잔액을 즉시 갱신한다.

## Solution1: 고객별 잔액 배열을 이용한 거래 시뮬레이션 

### 코드 설계
1. 고객 수 `N`과 거래 횟수 `M`을 입력받는다.
2. 고객별 잔액을 저장할 `long[] balances`를 생성한다.
   - 고객 번호를 인덱스로 바로 사용하기 위해 크기는 `N + 1`로 설정한다.
3. `M`개의 거래를 순서대로 처리한다.
   - 고객 번호 `customerNumber`
   - 거래 명령어 `command`
   - 거래 금액 `amount`
   - `command == 1`이면 해당 고객의 잔액에 `amount`를 더한다.
   - `command == 2`이면 현재 잔액이 `amount` 이상인 경우에만 차감한다.
4. 1번 고객부터 `N`번 고객까지 최종 잔액을 한 줄씩 출력한다.

### 코드 구현
- 핵심 포인트
  - 고객 번호를 배열의 인덱스로 사용하여 잔액을 O(1)에 조회하고 갱신한다.
  - 거래는 반드시 주어진 순서대로 처리한다.
  - 출금 전에 현재 잔액이 충분한지 검사한다.
- 시간복잡도: O(M + N)
- 공간복잡도: O(N)
