# Problem: Title of Problem
 
문제 요약: 원형으로 배치된 나무를 이동하며 조건을 만족하는 나무를 벌목하고, 모든 나무가 매 턴 성장할 때 최종 목재량을 구한다.

## 풀이

### 문제 정보
- 난이도: Lv 02 정도 
- 주제: 시뮬레이션, Lazy Update, 원형 배열
- 문제 핵심 
  - 전역 Offset으로 나무의 공통 성장 처리
  - Lazy Update로 O(NQ) → O(N + Q)
  - 원형 배열 인덱스 이동
- 최초 풀이: 260811 
- 수정 버전: 260907

### 접근법
1. Solution1: 전역 성장량을 이용한 Lazy Update
   - 매 턴 모든 나무를 직접 갱신하지 않고 공통 성장량만 누적하여 현재 나무의 높이를 O(1)에 계산한다.

## Solution1: 방식 (권장)
### 코드 설계
1. 나무의 초기 높이를 배열에 저장하고, 시작 위치를 0-based 인덱스로 변환한다.
2. 전체 나무의 공통 성장량 `growth`와 누적 목재량 `wood`를 0으로 초기화한다.
3. Q개의 이동 명령을 순서대로 처리한다.
   - 현재 나무의 실제 높이를 `tree[position] + growth`로 계산한다.
   - 실제 높이가 M 이상이면 해당 높이를 `wood`에 누적한다.
   - 벌목한 나무의 실제 높이가 0이 되도록 `tree[position] = -growth`로 갱신한다.
   - `L`, `R`, `S`에 따라 현재 위치를 이동한다.
   - 모든 나무를 직접 증가시키는 대신 `growth`를 1 증가시킨다.
4. Q번의 과정이 끝나면 누적 목재량 `wood`를 출력한다.

  - `System.out.println()`: 최종 누적 목재량을 출력한다.

### 복잡도
- 시간복잡도: `O(N + Q)`
  - O(N): N개의 초기 나무 높이 저장
  - O(Q): Q개의 명령을 각각 O(1)에 처리
- 공간복잡도: `O(N)`
  - N개의 나무 상태를 저장하는 배열
