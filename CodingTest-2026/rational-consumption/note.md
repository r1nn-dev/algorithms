# Problem: Rational Consumption
 
문제 요약: 물품과 가격이 주어질 때 가장 비싼 물품과 가장 저렴한 물품을 구하는 문제

## 풀이

### 문제 정보
- 난이도: Lv 01 
- 주제: 선형 탐색, 최솟값/최댓값
- 최초 풀이: 260811 
- 수정 버전: 260813 

### 접근법
1. Solution1: 선형 탐색
   - 물품을 하나씩 입력받으면서 현재 최소 가격과 최대 가격을 비교하여 갱신한다.
   - 최소/최대 가격이 변경될 때 해당 물품명도 함께 저장한다.


## Solution1: 선형 탐색 
### 코드 설계
1. 첫 번째 줄에서 물품의 개수 `N`을 입력받는다.
2. 최소/최대 가격과 해당 물품명을 저장할 변수를 초기화한다.
   - `minPrice = Integer.MAX_VALUE`
   - `maxPrice = Integer.MIN_VALUE`
   - `minName`, `maxName`
3. `N`번 반복하면서 물품명과 가격을 입력받는다.
   - 입력 한 줄을 공백 기준으로 물품명과 가격으로 분리한다.
   - 현재 가격이 `minPrice`보다 작으면 `minPrice`, `minName`을 함께 갱신한다.
   - 현재 가격이 `maxPrice`보다 크면 `maxPrice`, `maxName`을 함께 갱신한다.
4. 가장 비싼 물품과 가격을 먼저 출력하고, 다음 줄에 가장 저렴한 물품과 가격을 출력한다.

### Java
- 구현 파일: `Solution1.java`
- 핵심 문법:
  - `BufferedReader`: 입력을 한 줄씩 읽는다.
  - `StringTokenizer`: 한 줄을 공백 기준으로 물품명과 가격으로 분리한다.
  - `Integer.parseInt()`: 문자열 형태의 가격을 `int`로 변환한다.
  - `Integer.MAX_VALUE`: 최솟값 탐색을 위한 초기값으로 사용한다.
  - `Integer.MIN_VALUE`: 최댓값 탐색을 위한 초기값으로 사용한다.
  - `System.out.println()`: `품명 가격` 형식으로 결과를 출력한다.

### Python
- 구현 파일: `Solution1.py`
- 핵심 문법:
  - input(): 입력을 한 줄씩 문자열로 읽는다.
  - split(): 한 줄을 공백 기준으로 물품명과 가격으로 분리한다.
  - int(): 문자열 형태의 가격을 int로 변환한다.
  - float("inf"): 최솟값 탐색을 위한 초기값으로 사용한다.
  - float("-inf"): 최댓값 탐색을 위한 초기값으로 사용한다.
  - print(): 품명 가격 형식으로 결과를 출력한다.

### 복잡도
- 시간복잡도: O(N)
  - N개의 물품을 한 번씩 확인한다.
- 공간복잡도: O(1)
  - 물품 전체를 저장하지 않고 현재 물품과 최소/최대 정보만 저장한다.
