# Problem: Cloud Flag

문제 요약: 구름이 없는 칸마다 주변 8칸의 구름 개수를 확인하여, 값이 K인 깃발의 개수를 구한다.

## 풀이

### 문제 정보
- 난이도: Lv 01 정도
- 주제: 구현, 2차원 배열, 완전 탐색, 방향 배열
- 문제 핵심 
  - 빈 칸 기준 8방향 완전 탐색
  - 방향 배열로 주변 구름 개수 카운트
- 최초 풀이: 260811
- 수정 버전: 261003

### 접근법
1. Solution1: 빈 칸 기준 8방향 탐색 (권장)
   - 각 빈 칸에서 주변 8칸의 구름 개수를 직접 세어 값이 K인 칸을 찾는다.
2. Solution2: 구름 기준 주변 카운트 누적
   - 각 구름에서 주변 8칸의 카운트를 증가시킨 뒤 값이 K인 빈 칸을 찾는다.
   - 한계: 추가적인 N × N 카운트 배열이 필요하므로 Solution1보다 공간 사용량이 크다.


## Solution1: 빈 칸 기준 8방향 탐색 (권장)
### 코드 설계
1. N, K와 N × N 게임판을 입력받는다.
2. 8방향 이동을 위한 `dr`, `dc`와 정답을 저장할 `answer`를 초기화한다.
3. 게임판의 모든 칸을 순회한다.
   - 구름이 있는 칸은 건너뛴다.
   - 빈 칸에서는 방향 배열을 이용해 주변 8칸을 확인한다.
   - 범위 안에 있는 칸이 구름이면 `cloudCount`를 증가시킨다.
   - `cloudCount == K`이면 `answer`를 증가시킨다.
4. `answer`를 출력한다.

### Java
- 구현 파일: `Solution1.java`
- 핵심 문법:
  - `BufferedReader`: 입력을 한 줄씩 빠르게 읽는다.
  - `StringTokenizer`: 공백으로 구분된 입력값을 분리한다.
  - `int[][]`: 게임판을 2차원 배열로 저장한다.
  - `int[] dr`, `int[] dc`: 상하좌우와 대각선 8방향을 저장한다.
  - `continue`: 구름이 있는 칸이나 범위를 벗어난 좌표를 건너뛴다.
  - `System.out.println()`: 최종 깃발 개수를 출력한다.

### Python
- 구현 파일: `Solution1.py`
- 핵심 문법:
  - `sys.stdin.readline`: 입력을 빠르게 읽는다.
  - `map(int, input().split())`: 공백으로 구분된 입력을 정수로 변환한다.
  - `list(map(...))`: 게임판의 한 행을 리스트로 저장한다.
  - `directions`: 8방향 이동값을 튜플로 저장한다.
  - `for dr, dc in directions`: 주변 8방향을 순회한다.
  - `0 <= nr < N`: 이동한 좌표가 게임판 범위 안인지 확인한다.

### 복잡도
- 시간복잡도: O(N²)
- 공간복잡도: O(N²)


## Solution2: 구름 기준 주변 카운트 누적

### 코드 설계
1. N, K와 N × N 게임판을 입력받는다.
2. 각 칸 주변의 구름 개수를 저장할 N × N `count` 배열을 초기화한다.
3. 게임판의 모든 칸을 순회한다.
   - 구름이 있는 칸이면 주변 8방향을 확인한다.
   - 범위 안에 있는 주변 칸의 `count` 값을 1 증가시킨다.
4. 게임판을 다시 순회하며 빈 칸이면서 `count` 값이 K인 칸의 개수를 출력한다.

### Java
- 구현 파일: `Solution2.java`
- 핵심 문법:
  - `BufferedReader`: 입력을 한 줄씩 빠르게 읽는다.
  - `StringTokenizer`: 공백으로 구분된 입력값을 분리한다.
  - `int[][]`: 게임판과 주변 구름 개수 배열을 저장한다.
  - `int[] dr`, `int[] dc`: 주변 8방향을 표현한다.
  - `count[nr][nc]++`: 구름의 영향을 주변 칸에 누적한다.
  - `&&`: 빈 칸 여부와 주변 구름 개수를 동시에 확인한다.

### Python
- 구현 파일: `Solution2.py`
- 핵심 문법:
  - `sys.stdin.readline`: 입력을 빠르게 읽는다.
  - `list(map(int, ...))`: 게임판의 한 행을 정수 리스트로 저장한다.
  - `[[0] * N for _ in range(N)]`: N × N 카운트 배열을 생성한다.
  - `directions`: 주변 8방향 이동값을 저장한다.
  - `count[nr][nc] += 1`: 구름의 영향을 주변 칸에 누적한다.
  - `and`: 빈 칸 여부와 카운트 조건을 함께 확인한다.

### 복잡도
- 시간복잡도: O(N²)
- 공간복잡도: O(N²)
