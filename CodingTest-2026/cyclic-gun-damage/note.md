# Problem: Cyclic Gun Damage
 
문제 요약: 1부터 4까지 반복되는 공격력으로 적을 순서대로 쓰러뜨릴 때 필요한 총 발사 횟수를 구하는 문제 

## 풀이

- 주제: 구현, 시뮬레이션, 수학, 주기
- 문제 핵심 
  - 4발 단위 주기 처리
  - 주기 합을 이용한 연산 최적화

## Solution1: 4발 주기를 묶어서 처리하는 시뮬레이션
### 코드 설계
1. 적의 수 `N`과 각 적의 체력을 입력받는다.
2. 총 발사 횟수를 저장할 `long shots`를 초기화한다.
3. 각 적을 1번부터 순서대로 처리한다.
   - 현재 적의 체력을 `health`에 저장한다.
   - `1, 2, 3, 4`의 공격력 합은 10이므로 가능한 4발 묶음을 먼저 계산한다.
   - 적을 4발 묶음만으로 쓰러뜨리지 않도록 `(health - 1) / 10`개의 묶음만 처리한다.
   - 한 묶음마다 체력 10을 감소시키고 발사 횟수 4를 증가시킨다.
   - 남은 체력이 0 이하가 될 때까지 한 발씩 공격한다.
   - 현재 `shots`를 이용해 다음 공격력을 `(shots % 4) + 1`로 계산한다.
4. 모든 적을 쓰러뜨린 뒤 `shots`를 출력한다.
