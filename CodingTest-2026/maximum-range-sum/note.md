# Problem: Maximum Range Sum 
 
문제 요약: 배열을 재배열하여 주어진 모든 구간 합의 총합을 최대로 만드는 문제

## 풀이

### 문제 정보
- 난이도: Lv 02 
- 주제: 누적 합, 차분 배열, 정렬, 그리디
- 문제 핵심 
  - 차분 배열로 위치별 등장 횟수 계산
  - 배열과 등장 횟수를 같은 순서로 정렬
  - 대응 원소의 곱 누적
- 최초 풀이: 260729 
- 수정 버전: 260809 

### 접근법
1. Solution1: 차분 배열 + 정렬 
   - 각 위치의 구간 등장 횟수를 O(N + Q)에 계산한 뒤, 큰 원소를 등장 횟수가 큰 위치에 배치하여 최댓값을 구한다.

## Solution1: 차분 배열 + 정렬 

### 코드 설계

1. `N`, `Q`와 배열 `A`를 입력받는다.
2. 크기 `N + 1`의 차분 배열 `count`를 생성한다.
3. 각 구간 `[L, R]`에 대해 차분 배열을 갱신한다.
   - `count[L - 1]++`
   - `count[R]--`
4. 누적 합을 계산하여 각 위치가 몇 개의 구간에 포함되는지 구한다.
5. 배열 `A`와 위치별 등장 횟수 `count`를 각각 오름차순 정렬한다.
6. 같은 인덱스의 `A[i] × count[i]`를 모두 더한다.
7. 최종 합을 출력한다.

### 코드 구현

- 핵심 포인트
  - 차분 배열로 구간 빈도 계산
  - 큰 값과 큰 빈도를 대응
  - 최종 합은 `long` 사용
- 시간복잡도: O(N log N + Q)
- 공간복잡도: O(N)
